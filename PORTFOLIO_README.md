## Projects Completed

### Task 1: Iris Flower Classification

**Problem:** Classifying iris flowers into three species using measurements of their flowers.

**Dataset:** Iris dataset containing 150 records and five columns.

**Techniques Used:**
- Data exploration and analysis
- Data inspection and preparation
- Logistic Regression
- Decision Tree Classification
- Model evaluation
- Confusion matrix analysis
- Model comparison

**Results:**
- Logistic Regression accuracy: 96.67%
- Decision Tree accuracy: 93.33%

**Files:**
- `Task1.ipynb`
- `iris.csv`
- `model_comparison.csv`

### Task 2: California Housing Price Prediction

**Problem:** Predicting median house values in California districts using geographical, housing and demographic information.

**Dataset:** California Housing dataset containing 20,640 records.

**Techniques Used:**
- Data exploration
- Missing-value treatment
- Median imputation
- Data preprocessing
- One-hot encoding
- Train-test splitting
- Regression modelling
- Feature importance analysis

**Models Evaluated:**
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

**Best Model:** Random Forest Regressor

**Results:**
- MAE: 31,636.19
- MSE: 2,398,820,115.38
- R²: 0.8169 (81.69%)

**Files:**
- `California_Housing_Price_Prediction.ipynb`
- `housing.csv`
- `README.md` (California project report)
